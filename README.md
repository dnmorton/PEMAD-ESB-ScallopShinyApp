This Shiny App contains data from the annual Atlantic sea scallop fisheries-independent dredge survey. Data from this survey has been collected since 1977 to inform abundance estimates in scallop stock assessments. The purpose of this application is to provide an improved user experience for visualizing and interpreting the raw survey data that is collected. The data is updated annually at the completion of each survey's data audit. To run the app, open the app.R file in the ScallopShinyApp folder and press "Run App." The application is supported by a CSS file that handles the styling of the app and an R Markdown that contains the text found in the app.
